# Бот для приёма заявок

1. Создайте бота у @BotFather, скопируйте токен.
2. `cp .env.example .env` и впишите `BOT_TOKEN` и свой `ADMIN_IDS` (id узнать у @userinfobot).
3. `pip install -r requirements.txt && python bot.py`

## Админ
- `/admin` — панель: новые заявки, пользователи (поиск), забаненные, статистика.
- Под заявкой: ✅ Принять / ❌ Отклонить (без причины / с причиной).
- Бан ответом на карточку или сообщение клиента: `/ban 7d причина` (срок: 30m, 2h, 7d, 2w; без срока — навсегда, причина необязательна). Также `/ban @user 1d`, `/ban 123456`, `/unban`.
- Любой ответ (reply) на карточку/сообщение клиента уходит клиенту от имени бота — анонимный чат.
